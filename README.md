# Maa Annapurna Mandir — Professional Pro V3

## What changed
- More polished motion system: reveal + blur, hover lift, image zoom, light sweep, subtle glow, responsive motion.
- Better visual hierarchy and spacing so sections fit cleanly on desktop/tablet/mobile.
- Hero remains large and cinematic using the supplied Maa Annapurna image.

- Full private CMS for the homepage.

## Admin controls
Hero & Homepage, Announcements, Daily Darshan/Aarti, Events, Gallery/Image uploads, YouTube/Live/Shorts, Social links, and Enquiries.

## Supabase
Put the Project URL and publishable/anon key into `app.js` and `admin.js`. Never use the service-role/secret key in browser code.

The existing database schema and `temple-gallery` Storage bucket can be used.
